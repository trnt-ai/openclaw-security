# Contributing

Found a false positive, a missed attack pattern, or a usability problem?

Please open an issue and include:

- What happened
- What you expected
- Steps to reproduce
- Relevant environment details
- Screenshots or logs if helpful

Issue types:

- False positive
- False negative
- Feature request
- Bug report
